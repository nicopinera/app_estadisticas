# Reglas para realizar un commit

Los commit tienen que seguir el siguiente formato:

```text
<tipo de cambio> : descripcion corta
```

## Tipos de cambios

- FEAT: Nueva funcionalidad
- FIX: Corregir bug o errores
- DOCS: Cambios en la Documentacion
- STYLE: Cambios de formato
- REFACTOR: Cambios de codigo
- PERF: Mejoras de rendimiento
- TEST: Agregado o correccion de test
